### 프로젝트 소개
이 프로젝트는 홍익대학교 Information Design(1) 수업에서 진행한 인터랙티브 인포메이션 디자인 작업입니다.<br>
그 중 제가 맡은 "음악"파트를 직접 경험해보실 수 있습니다.<br>
화양연화 카페에서 흘러나오는 음악 데이터를 수집해 시각화함으로써 카페의 분위기를 인터랙티브 인포메이션 형태로 관람할 수 있도록 제작했습니다.<br>
<br>
